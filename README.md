# 🤖 Gemini Phone Agent - সম্পূর্ণ ব্যবহার নির্দেশিকা (Complete Manual)

এই ফোল্ডারে আপনার তৈরি করা নিজস্ব অ্যান্ড্রয়েড এআই এজেন্ট অ্যাপের সমস্ত গুরুত্বপূর্ণ ফাইল, স্ক্রিপ্ট এবং নির্দেশিকা একত্রিত করে দেওয়া হলো।

---

## 📂 এই ফোল্ডারের ফাইলসমূহ (File Overview)

1. **`GeminiAgent.apk`**  
   👉 সরাসরি ফোনে ইনস্টল করার জন্য প্রস্তুত সর্বশেষ সাইন করা APK ফাইল।
2. **`1_BUILD_APK.bat`**  
   👉 পিসিতে যেকোনো সময় লোকালভাবে নতুন APK তৈরি করতে এই ফাইলে ডাবল-ক্লিক করুন।
3. **`2_PUSH_UPDATE_TO_GITHUB.bat`**  
   👉 পিসিতে কোড পরিবর্তন করার পর গিটহাবে পুশ করার স্ক্রিপ্ট। এটি পুশ করার সাথে সাথে আপনার ফোনে ওভার-দ্য-এয়ার (OTA) আপডেট নোটিফিকেশন চলে যাবে!
4. **`3_OPEN_PROJECT_FOLDER.bat`**  
   👉 অ্যাপটির মূল সোর্স কোড ফোল্ডার সরাসরি ওপেন করার শর্টকাট।

---

## 📱 পার্ট ১: ফোনে প্রথমবার ইনস্টলেশন ও সেটআপ

### ধাপ ১: APK ফোনে নেওয়া
* ফোল্ডারে থাকা `GeminiAgent.apk` ফাইলটি ডেটা ক্যাবল দিয়ে ফোনের **Downloads** ফোল্ডারে কপি করুন (অথবা WhatsApp / Google Drive দিয়ে ফোনে পাঠিয়ে নিন)।

### ধাপ ২: ফোনে ইনস্টল করা
* ফোনে ফাইলটিতে ট্যাপ করে **Install** বাটনে চাপুন।
* **Play Protect / সিকিউরিটি সতর্কবার্তা এলে:**
  1. স্ক্রিনে যদি "Blocked by Play Protect" বা "Unsafe app" আসে, ঘাবড়াবেন না।
  2. নিচে ছোট করে লেখা **"More details"** (বা "আরও বিবরণ")-এ চাপুন।
  3. এরপর **"Install anyway"** (বা "যেভাবেই হোক ইনস্টল করুন")-এ চাপুন।  
  *(একবার এটি অনুমোদন করলে ফোনের সিকিউরিটি আপনার ডিজিটাল সিগনেচারকে আজীবনের জন্য বিশ্বস্ত হিসেবে চিনে নেবে)*

### ধাপ ৩: প্রাথমিক সেটিংস
1. অ্যাপটি ওপেন করুন। আপনার ফোনের নোটিফিকেশন বারে **"Gemini Agent Active"** নোটিফিকেশন দেখতে পাবেন (যার অর্থ অ্যাপটি ব্যাকগ্রাউন্ডে সবসময় সজাগ থাকবে)।
2. উপরের ডানদিকের ⚙️ **Settings** আইকনে ট্যাপ করুন:
   * **Gemini API Key:** আপনার Google AI Studio থেকে নেওয়া `AIzaSy...` কি বসান।
   * **GitHub Repo:** লিখুন `gr30812/gemini-phone-agent`
   * **"সংরক্ষণ করুন"** বাটনে চাপুন।

## 💬 পার্ট ২: কীভাবে এজেন্ট ব্যবহার করবেন

* নিচের চ্যাট বক্সে আপনার নির্দেশনা টাইপ করুন (বাংলা বা ইংরেজি যেকোনো ভাষায়)।
* **উদাহরণ:**
  * *"workspace-এ একটা calculator.py বানিয়ে ওটা টেস্ট করো"*
  * *"আমার ওয়ার্কস্পেসে কী কী ফাইল আছে লিস্ট দেখাও"*
* এজেন্ট নিজে সিদ্ধান্ত নিয়ে কোড লিখবে, ফাইল রিড/রাইট করবে এবং আউটপুট আপনার চ্যাট স্ক্রিনে সুন্দরভাবে তুলে ধরবে।
* আপনি অন্য কোনো অ্যাপে কাজ করলেও বা ফোন লক করলেও ব্যাকগ্রাউন্ড সার্ভিস এজেন্টের সেশন সচল রাখবে।

## 🚀 পার্ট ৩: পিসিতে কোড আপগ্রেড ও ফোনে স্বয়ংক্রিয় আপডেট (OTA Update)

ভবিষ্যতে যখনই আপনি অ্যাপে নতুন কোনো ফিচার যোগ করবেন:

### ১. কোড পরিবর্তন করুন
`3_OPEN_PROJECT_FOLDER.bat` চালিয়ে সোর্স কোড ফোল্ডার ওপেন করে যেকোনো ফাইল এডিট করুন (যেমন নতুন টুলস যোগ করতে `GeminiApiClient.kt`, বা নতুন ইউআই যোগ করতে `AgentChatScreen.kt`)।

### ২. গিটহাবে পুশ করুন (১-ক্লিকে)
* এই ফোল্ডারের **`2_PUSH_UPDATE_TO_GITHUB.bat`** ফাইলে ডাবল-ক্লিক করুন।
* আপনি কী পরিবর্তন করেছেন তা এক লাইনে লিখে **Enter** চাপুন (যেমন: *Added voice feature*)।
* স্ক্রিপ্টটি নিজে থেকেই ভার্সন নম্বর ১ বাড়িয়ে গিটহাবে পুশ করে দেবে!

### ৩. ফোনে স্বয়ংক্রিয় আপডেট গ্রহণ
* পুশ হওয়ার সাথে সাথে গিটহাবের ফ্রি ক্লাউড সার্ভার নিজে থেকে ২ মিনিটের মধ্যে নতুন APK বিল্ড করে নেবে।
* এবার আপনার ফোনে অ্যাপটি ওপেন করলেই উপরে নীল রঙের নোটিফিকেশন ব্যানার ভেসে উঠবে:  
  👉 **"🚀 নতুন আপডেট প্রস্তুত! [আপডেট করুন]"**
* **"আপডেট করুন"** বাটনে চাপলেই নতুন ভার্সনটি স্বয়ংক্রিয়ভাবে ডাউনলোড হয়ে ফোন এক ক্লিকে আপডেট হয়ে যাবে! কোনো কেবল লাগবে না!

## 🛠️ টেকনিক্যাল আর্কিটেকচার (For Developers)

* **UI Framework:** Kotlin + Jetpack Compose (Material 3 Dark Theme)
* **Target OS:** Android 8.0 (API 26) থেকে Android 15/16 (API 35)
* **Background Engine:** Android Foreground Service with Partial WakeLock
* **Networking & AI:** OkHttp + Google Gemini 3.8 Flash direct REST API
* **OTA Engine:** In-App GitHub Releases Auto-Updater with Android FileProvider
* **Signing Keystore:** Custom 2048-bit RSA Certificate (`keystore.jks`) valid for 10,000 days
* **Repository:** `https://github.com/gr30812/gemini-phone-agent`
